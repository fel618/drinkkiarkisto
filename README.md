## Drinkkiarkisto

**Drinkkiarkisto** is a PHP-based web application for managing and searching drink recipes.

The project includes:

* User registration and login with role-based access (`user` / `admin`)
* Session-based authentication
* Drink recipe creation and suggestions
* Ingredient management
* Search by drink name or ingredient
* Admin approval and deletion of recipes
* User management
* Responsive navigation and styling with CSS
* JavaScript functionality for dynamically adding ingredients
* MySQL/MariaDB database integration

The project was developed as a school assignment using **PHP, MySQL/MariaDB, HTML, CSS, and JavaScript**, with **XAMPP** used as the local development environment.
